# 首版验证记录

日期：2026-11-17。

## 环境

- Windows；工作区默认 Python 3.11.4；另用独立虚拟环境 Python 3.13.5 验证。
- Tkinter 8.6；系统安装 Huihui 中文、Zira 英语、Haruka 日语语音。
- FFmpeg / FFprobe 8.0 系列；在线依赖 edge-tts 7.3.1。
- 代码保存在项目目录，音频及独立环境位于 `assets`。

## 书库兼容性

只读扫描 `library` 中的 EPUB：

- 绝大部分成功提取；个别 EPUB 没有可朗读正文，程序明确报错。
- PDF 未纳入转换支持。扫描验证的是结构解析和正文提取，不代表已逐本人工审校，也未批量合成全书库。

## 自动验证

`python -m unittest discover -s tests -v`：12 项通过，Python 3.11 和独立环境 3.13 均通过。
覆盖 EPUB spine 顺序、插图与元数据过滤、注音过滤、TXT 编码、分段完整性、非法章节路径、
合成失败后的续转、取消清理、缓存损坏、配置变化与文件名兼容性。

桌面界面冒烟验证通过：扫描书库、搜索示例关键词、载入示例、正文预览、
多章节选择、离线/在线切换。独立环境也成功创建 Tk 窗口。

## 实际音频

- 离线示例两章：MP3、22,050 Hz、单声道，时长分别为 13.48 秒、14.62 秒。
- Edge 晓晓短文本示例：成功合成并合并 MP3，时长 11.64 秒；在线请求只使用项目自带示例文本。
- 示例 EPUB 第一卷前 180 字：离线试听 MP3，存入 `preview`。
- 同卷完整序章：1,691 字符，分成 2 段，合并为 410.18 秒、4,923,394 字节 MP3，存入 `output`。
- 再次运行同一序章任务：命中已完成章节校验，直接复用 MP3。

音频通过 FFprobe 验证编码和时长。未进行人工听感评分或全文逐字核对。
离线与在线验证文件分别保存在 `qa/offline-smoke` 和 `qa/edge-smoke`。
